
# GitHubProfileFinder — Buscador de Perfis do GitHub

Aplicação web desenvolvida com Vue.js para buscar perfis de usuários do GitHub e visualizar suas informações de forma simples e intuitiva.

O projeto foi desenvolvido durante meus estudos de Vue.js, com o objetivo de praticar conceitos de desenvolvimento front-end, componentização e consumo de dados.
</br>
## Sobre o projeto

O GitHubProfileFinder permite pesquisar usuários do GitHub por meio de seus nomes de usuário e consultar informações disponibilizadas pela plataforma.

O projeto faz parte da minha jornada de aprendizado em Análise e Desenvolvimento de Sistemas e está voltado à prática de desenvolvimento de interfaces web com Vue.js.
</br>

## Funcionalidades

- Busca de perfis de usuários do GitHub.
- Consulta de informações públicas dos usuários.
- Exibição dos resultados em uma interface web.
- Interface desenvolvida com componentes Vue.js.

## Tecnologias utilizadas

- Vue.js
- JavaScript
- Vite
- HTML5
- CSS3

</br>
## Arquitetura e organização

O projeto utiliza Vue.js para estruturar a interface em componentes reutilizáveis, facilitando a organização e a manutenção do código.

O Vite é utilizado como ferramenta de desenvolvimento e build da aplicação.

## Como executar o projeto

### Pré-requisitos

- Node.js.
- npm.

</br>
###Passos

1. Clone o repositório:

   ```bash
   git clone https://github.com/GSegatto/GitHubProfileFinder.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd GitHubProfileFinder
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Execute a aplicação em ambiente de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Acesse no navegador o endereço local informado pelo terminal.
